# Correctif navbar responsive

Le bouton **Écrire au Président** et le bouton **Recherche** restent maintenant visibles à toutes les largeurs, y compris mobile.

- Aucun `display: none` ne masque le CTA.
- Sur tablette et mobile, les deux actions sont ancrées à droite de la barre.
- Les autres liens peuvent défiler horizontalement derrière elles.
- Le bouton **Écrire au Président** garde son texte, mais devient plus compact sur petit écran.
- Le bouton Recherche reste accessible en permanence.
- Aucun hamburger n'a été ajouté.

Fichiers modifiés : `index.html`, `site-shell.js`, `rdc.css`.
