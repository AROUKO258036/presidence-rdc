# Pack La Présidence

Copiez les dossiers de ce pack à la racine de votre projet actuel. Le pack ne remplace pas votre `index.html`, votre recherche ni votre page Écrire au Président.

## Dossiers ajoutés
- `presidence/`
- `president/le-president/`
- `president/premiere-dame/`
- `le-cabinet/`
- `anciens-presidents/`
- `symboles-de-la-republique/`
- `textes-fondateurs/`
- `assets/president.png`
- `assets/palais-blanc.png`
- `assets/first-lady-placeholder.svg`

La photo de la Première Dame est volontairement un placeholder : remplacez `/assets/first-lady-placeholder.svg` par une photo officielle validée lorsque vous l'aurez.
