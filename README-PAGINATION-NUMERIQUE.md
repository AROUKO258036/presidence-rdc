# Pagination numérique

Mise à jour des paginations de liste :

- `actualites/` : pagination numérique 1 à 134 puis `»`.
- `conseil-de-ministres/` : pagination numérique 1 à 18 puis `»`.
- La page active est affichée dans un carré bleu.
- La grille se replie automatiquement sur tablette et mobile.
- Les anciens boutons `Précédent / Suivant` ont été supprimés de ces pages de liste.

Les liens sont actuellement des ancres de structure (`#page-N`) : ils sont prêts à être reliés ensuite à une pagination dynamique ou à des pages serveur sans modifier le design.
