# Mise à jour photos officielles

- La page `conseil-de-ministres/` ne contient plus le bloc « Partager cette page ».
- Les cartes et pages Conseil des ministres utilisent désormais les photos officielles de `presidence.cd`.
- Les cartes et pages Actualités utilisent les photos officielles de `presidence.cd`.
- Les albums n’emploient plus de placeholders locaux. Lorsqu’une seule image officielle a été vérifiée pour une publication, l’album conserve une seule diapositive plutôt que d’afficher une image d’un autre événement.
- Pour l’article CAN 2027, les deux images d’album fournies sont conservées : `IMG-20260924-WA0101.jpg` puis `IMG-20260924-WA0098-compressed.jpg`, suivies de l’image principale officielle.
