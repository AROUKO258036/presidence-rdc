# Correctif newsletter + navigation par rubrique

Base : `rdc-site-complet-v2-navbar-slider-video-footer.zip`.

## Changements

- Le bandeau pré-footer contient désormais un bloc Newsletter et un bouton **S'inscrire à la newsletter**.
- Le bouton ouvre une modale avec champ e-mail puis la modale de confirmation.
- Les libellés avec dropdown sont maintenant des liens réels : Actualités, La Présidence, Afrique, Programmes, Médias, Ressources.
- Desktop : le dropdown s'ouvre au survol et un clic ouvre la page principale.
- Mobile/tablette : premier appui ouvre le dropdown, second appui sur le même libellé ouvre la page principale.
- Création des pages d'aperçu `/presidence/`, `/afrique/`, `/programmes/`, `/medias/`, `/ressources/`.
- Le slider horizontal, la vidéo Hero, le footer commun et les boutons `Écrire au Président` / recherche restent inchangés.
