# Synchronisation globale — pré-footer et partage

Cette version synchronise toutes les occurrences existantes de :

- **Partager cette page**
- **Partager cet article**
- **Pré-footer / Newsletter**

Règles appliquées :

1. Les blocs de partage utilisent les vraies icônes SVG WhatsApp, Facebook, X, E-mail et LinkedIn.
2. Le pré-footer utilise partout le format compact : « Abonnez-vous à la newsletter de la Présidence » + bouton « S'inscrire ».
3. L'identité « Présidence de la République » est placée sous le bouton avec la bande bleu / jaune / rouge.
4. La page d'accueil, la page Actualités et toutes les pages détail d'actualité existantes ont été synchronisées.
5. L'album du premier article utilise `IMG-20260924-WA0101.jpg` puis `IMG-20260924-WA0098-compressed.jpg`.
