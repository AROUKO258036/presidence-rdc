# Pagination interactive

Mise à jour appliquée aux pages **Actualités** et **Conseil des ministres**.

- compteur de résultats dynamique (`1–6 sur 423 résultats` sur Actualités) ;
- boutons **Précédent** et **Suivant** fonctionnels ;
- clic sur un numéro de page met à jour la page active ;
- URL synchronisée avec `?page=N` sans rechargement ;
- navigation précédent/suivant du navigateur prise en charge ;
- animation légère de la grille lors d’un changement de page ;
- les numéros de page et le compteur restent synchronisés.

La base contient actuellement six cartes locales par liste. Le système de pagination est prêt pour brancher davantage de données sans modifier l’interface.
